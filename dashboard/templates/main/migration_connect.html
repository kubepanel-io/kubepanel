How to create a WHM API Token

  1. Log in to WHM on the source server (port 2087)
  2. Go to Development > Manage API Tokens
  3. Click "Create" to generate a new token
  4. Give it a name (e.g., "KubePanel Migration")
  5. Copy the token and paste it above

Note: You need WHM/root access to list all domains on the server. API tokens are more secure than passwords and can be revoked at any time.
